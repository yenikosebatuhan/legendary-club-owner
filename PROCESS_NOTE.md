# Process Note

I built this landing page with **React + Vite + Tailwind CSS** and **lucide-react** icons, using AI as a co-pilot across the whole loop — copywriting, code iteration, and visuals. **Google Gemini** generated every image asset in `public/assets/`, including the **LCO crest logo** (`logo-lco.png`), the hero owner-box scene, the How-It-Works panels, the leaderboard backdrop, the empty president's chair, and the pitch texture; all readable text stays as real HTML so imperfect AI-baked text is never relied upon. I made the interactive **Build Your Club** flow the centerpiece because it lets the player *feel* the football-ownership fantasy immediately — four quick choices drive a live in-game "Club License" preview (generated crest, opening fixture, board confidence) that then drops their club onto the season leaderboard at #6. The whole page leans on "show, don't tell": short football copy, strong imagery, and game-style UI cards rather than SaaS-style paragraphs. With more time I would wire the flow to real gameplay screenshots and a genuine waitlist/sign-up funnel, and instrument the onboarding steps with analytics to see where players drop off.
